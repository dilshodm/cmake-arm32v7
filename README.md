# Static cmake for linux arm64, amd64, arm32v7

Download binaries releases page.

## Docker images

Build docker images for 3 platforms using `docker-build.sh`

## Build cmake binaries

Build cmake binaries using script. It creates static cmake for linux arm64 (aarch), amd64 (x64) and arm32v7 (armhf).

These binaries can be installed in any linux distro, even the old ones.
